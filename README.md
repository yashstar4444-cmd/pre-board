- **Red & Blue Blood Theme**: `WRATH OF YASH (YUVV)` in intense dark blood-red gradient, `aukat hai to 100 percant liya` in dark mode blue, and continuous blinking marquee `BLEED JIWESH WITH THOUSAND OF CUTS`.

## 🚀 How to Publish on GitHub Pages (Step-by-Step)

### Option 1: Via GitHub Web Interface (Easiest)

1. Go to [github.com/new](https://github.com/new) and create a new repository (e.g. `pre-board-2026`). Set it to **Public**.
2. Click **"uploading an existing file"**.
3. Select and drag all files & folders inside `c:\Users\Railnet-01\Desktop\pre board\` into GitHub:
   - `index.html`
   - `.nojekyll`
   - `css/`
   - `js/`
   - `assets/`
4. Click **Commit changes**.
5. Go to **Settings** > **Pages** (on the left menu).
6. Under **Build and deployment**, set Source to `Deploy from a branch`.
7. Under Branch, select `main` and `/ (root)`, then click **Save**.
8. Within 1 minute, your website will be live at:
   `https://<your-username>.github.io/pre-board-2026/`
